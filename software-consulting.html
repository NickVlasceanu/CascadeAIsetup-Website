FAQ

Common questions

Is the consultation really free?

Yes. The first consultation is on me, no card, no commitment. It's how we both find out whether this is a good fit before any money changes hands.

What can you actually build?

Websites and web apps, front-end and UI work, and backend logic and integrations. If you're not sure whether something fits, ask during the consultation and I'll tell you honestly.

How does billing work?

A flat $50 an hour after the free consultation, billed for the time we use. No retainer, no lock-in. You can stop whenever you like.

What are AI coding agents, and why would I want one?

Tools like Claude Code let you build and change software by describing what you want in plain English. This allows even those with limited programming experience to build and modify software. Set up well, they save real time. I get you onboarded so they help instead of getting in the way.

Do you work remotely?

Yes, most of this works great over a call and screen share. I'm local to the Pacific Northwest, so in-person is on the table too.

Why should I trust a college student?

Because the consultation is free and you're never locked in. You see how I work before you pay, and you can walk away any time.
